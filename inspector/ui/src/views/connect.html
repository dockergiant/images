API & extensions

Read Inspector's answers where you look at the shop: a badge on every shop page, a DevTools panel next to Network, or your own script against /api/v1.

The read API is open to every origin, so any website open in this browser can read this shop's traces and cache through . Writes stay on this page, behind the confirm dialog.

Userscript badge

Tampermonkey · Violentmonkey

A small badge in the corner of each shop page: the Varnish result, PHP time, SQL calls and N+1 count. Click it for the cost strip and the three hottest spans, each linked to its trace here.

  1. Install Tampermonkey or Violentmonkey in this browser.
  2. Open the userscript below. The manager shows it for ; click Install.
  3. Reload a shop page. The badge sits bottom right; "Hide on this site" in its popover remembers the choice.
Install the userscript roll-inspector.user.js

DevTools panel

Chrome · Edge · MV3

A "Roll Inspector" tab in DevTools that lists the page's document and XHR/fetch requests. It joins each one through its X-Varnish header and shows the cost strip and bottlenecks.

  1. Download the zip and unzip it.
  2. Open , switch on Developer mode, click Load unpacked and pick the roll-inspector folder.
  3. Open DevTools on a shop page, pick the Roll Inspector tab and reload. Shops outside .test need "Allow every site" in its options.
Download the extension roll-inspector.zip
